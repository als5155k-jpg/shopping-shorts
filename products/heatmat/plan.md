자막 강조 단어(#F4C70F): 접어서, 냉기, 파우치, 오십에 백팔십, 백십 볼트, 고정댓글

- 자막에서는 숫자를 `50×180cm`, `110V`로 바꿔 표시한다(음성은 읽는 대로).
- 의성어·의태어 없음(Kanna 발음 이슈).
- 이전 대본의 "새벽 세 시에 깼다", "옆 텐트 분이 꺼내 줬다"는 지어낸 후기라 뺐다.

## 4. 소스
현재 사용 권한이 확인된 영상 없음. 아래 순서로 확보한다.
1. 판매자에게 상세페이지 영상·이미지 사용 허락 요청(`CHANNEL_GUIDE.md` 9장 문구)
2. 허락이 없으면 아래 촬영 가이드로 직접 촬영
3. 텐트·캠핑장 분위기 컷만 상업용 스톡으로 보충(라이선스 링크 기록)

(이전 버전의 해외 영상 검색 키워드는 다운로드 금지 방침에 따라 삭제)

## 5. 촬영 가이드 (세로 9:16, 1080×1920 이상, 30fps, 각 컷 4~6초 넉넉히)
| # | 장면 | 구도·앵글 | 연출 포인트 |
|---|---|---|---|
| 1 | 파우치에서 매트 꺼내기 | 위에서 내려다보기, 손과 파우치가 화면 가운데 아래 | 썸네일 A용. 위쪽 30%는 바닥만 보이게 |
| 2 | 매트를 접어 파우치에 넣기 | 1과 같은 구도, 역순 | 접는 과정이 한 번에 보이게 끊지 않고 촬영 |
| 3 | 펼친 매트 전체 | 매트 길이 방향이 세로가 되게 위에서 | 50×180 크기가 한눈에 보이게 |
| 4 | 컨트롤러·전원 연결 | 손 클로즈업 | 표시등이 켜지는 순간 |
| 5 | 매트 위에 앉아 담요 덮기 | 눈높이, 사람 상반신 + 매트 | 얼굴 노출 원치 않으면 목 아래만 |
| 6 | 텐트·차박 공간에 깐 모습 | 텐트 입구에서 안쪽으로 | 실내 촬영이면 거실 바닥도 가능(대본의 "캠핑" 장면은 6번 또는 스톡) |
| 7 | 가방 한 칸에 파우치 넣기 | 백팩 위에서 | 부피가 작다는 걸 보여주는 비교 컷 |

- 화면 우상단(워터마크 자리)과 위쪽 22~30%(상단 문구 자리)에는 제품의 중요한 부분이 오지 않게 찍는다.
- 다른 브랜드 로고가 보이는 소품은 치운다.

## 7. CapCut 프로젝트 만들기 (PC에서 실행)
```
pip install pycapcut pillow
python tools/make_capcut_draft.py products/heatmat/config.json
```
- CapCut 프로젝트 `heatmat_shorts_v2`가 생기고, 장면 자리표시 이미지는 `C:/CapCutAssets/heatmat_ad_v2/placeholders/`에 만들어진다.
- CapCut 프로젝트 폴더가 기본 위치가 아니면 `--drafts "<경로>"`를 붙인다. 같은 이름이 있으면 CapCut을 닫고 `--replace`.
- 트랙: 장면 / 자막(크기 15, 강조 단어 노랑) / 하단 노란 문구 / 상단 흰색 문구 / 썸네일 제목 2줄(맨 앞 1프레임) / YOGEOTTAE / [광고]
- 촬영 영상이 생기면 회색 장면 클립을 우클릭 → 교체. 실행 결과에 몇 초에 어떤 컷을 넣을지 목록이 나온다.
- 자막 타이밍은 추정치. 음성을 넣은 뒤 자막을 음성에 맞춰 다시 맞춘다.
